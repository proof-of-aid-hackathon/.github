# Contributing

Contributions are welcome.

## Getting started

1. Fork or clone the repository.
2. Create a branch for your change.
3. Keep changes focused and easy to review.
4. Test your changes locally.
5. Open a pull request with a short explanation of what changed and why.

## Guidelines

* Prefer small, focused pull requests.
* Follow the existing code style and project structure.
* Add or update tests when relevant.
* Avoid unrelated refactoring in the same pull request.
* Open an issue first for larger changes or architectural proposals.

By contributing, you agree that your contributions may be distributed under the repository's license.
