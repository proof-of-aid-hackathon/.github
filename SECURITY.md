# Security

Security issues should not be reported through public GitHub issues.

If you discover a vulnerability, please report it privately to the project maintainers with:

* a description of the issue
* steps to reproduce it
* the potential impact
* any suggested fix, if known

Please avoid exploiting the vulnerability beyond what is necessary to demonstrate the issue, and do not disclose it publicly until it has been reviewed.

Security reports will be investigated as quickly as practical.
