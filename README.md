# Proof of Aid

Organization-level GitHub configuration and community files for **Proof of Aid**.

The public organization profile is defined in [`profile/README.md`](profile/README.md).

Proof of Aid is developing open infrastructure for humanitarian accountability, connecting verified needs, funding, settlement, delivery, and outcome evidence into one auditable history.

Read the [proposal and roadmap](https://proof-of-aid.lovable.app/) for the planned protocol and initial non-custodial tracker pilot.
